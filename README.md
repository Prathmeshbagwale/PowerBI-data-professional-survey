## 📌 Project Overview

A professional **Excel data analysis and dashboard project** using the Bike Buyers dataset to identify customer purchasing patterns across demographics, income levels, and regions. Built with advanced Excel techniques used daily in business analyst, data analyst, and MIS reporting roles.

---

## 📦 Dataset

| Detail | Info |
|--------|------|
| **Dataset** | Bike Buyers Dataset |
| **Source** | [Download from Kaggle →](https://www.kaggle.com/datasets/heeraldedhia/bike-buyers) |
| **Alternate Source** | [Alex The Analyst — GitHub →](https://github.com/AlexTheAnalyst/Excel-Tutorial/blob/main/Excel%20Project%20Dataset.xlsx) |
| **Rows** | ~1,000 customer records |
| **Key Columns** | Income, Age, Gender, Marital Status, Region, Occupation, Commute Distance, Purchased Bike |

> 💡 Download the dataset from either link above and open it in Excel or Google Sheets — no installation required.

---

## ❓ Business Questions Answered

- What **income range** is most associated with bike purchases?
- How does **commute distance** affect the likelihood of buying a bike?
- Which **age groups and occupations** drive the most purchases?
- How do purchase rates compare **across regions** (Europe, Pacific, North America)?
- Does **marital status or home ownership** influence buying behaviour?

---

## 🔍 Key Features

| Feature | Details |
|---------|---------|
| **Pivot Tables** | Aggregated summaries by gender, region, age group, occupation |
| **Dynamic Charts** | Bar, line, and combo charts linked live to Pivot Tables |
| **Slicers** | One-click interactive filtering across the entire dashboard |
| **Conditional Formatting** | Traffic-light highlights for high/medium/low purchase rates |
| **Advanced Formulas** | `XLOOKUP`, `SUMIF`, `COUNTIF`, `IF`, `IFERROR`, `AVERAGEIF` |
| **Data Cleaning** | Removed duplicates, standardised age buckets, fixed blank fields |
| **MIS-Style Layout** | Executive summary view with structured, clean visual design |
